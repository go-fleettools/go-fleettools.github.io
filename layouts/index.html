Tools that answer for a whole fleet,
and say when they could not look.

go-fleettools holds the small Go programs a fleet of hundreds of repositories needs and nobody wants to do by hand: sweeps (red branches, stale toolchains, unbounded readers, landing drift), a mutation check that proves a test can fail, a waiter that refuses to call an empty check list a pass, and a fuzz runner. They also hold the landing kit shared by the go-* landings. Each one says so out loud when it read nothing.

What they have in common

Absence is never evidence.

Each tool was built after a wrong answer cost something, and each README says which. The same few rules recur.

🔇

Silence is not a pass

prwait refuses an empty check list; mutate exits 0 only when the suite went red; a sweep that reads nothing exits non-zero instead of reporting a clean fleet.

📅

Every answer carries its date

fleetfind prints the date of the inventory it answers from and warns when it is old: a "nothing matches" is only as good as when it was measured.

🔎

A lead, not a verdict

unbounded and landingdiff report where to look, never that something is broken, and say what they cannot see.

🧪

A control that could fail

The tools are tested against a planted defect: fuzzrun against a failing target, landingkit against a tinted background, so that "found nothing" means something.
